# Registro de decisões

## Estado atual

Direções confirmadas pelo usuário: começar pelo planejamento; construir para portfólio sem vendas reais; representar uma loja própria com fornecedores ou dropshipping; buscar uma experiência completa desde a concepção. Não há aprovação de stack, fornecedor específico, orçamento ou escopo funcional detalhado.

## Modelo para registrar uma escolha

```text
ID e título:
Status: proposta / aceita / substituída
Data:
Responsável pela decisão:
Contexto e requisitos:
Alternativas consideradas:
Decisão e justificativa:
Custos, limitações e consequências:
Documentos e tarefas afetados:
Condições para reavaliar:
```

Preservar decisões substituídas com referência à nova escolha. Para fornecedores e tecnologias, verificar documentação e preços atuais no momento da avaliação; nenhuma cotação foi realizada nesta etapa.
