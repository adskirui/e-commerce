# Projeto de e-commerce

Status: descoberta e planejamento. Ainda não há aplicação implementada.

Objetivo confirmado: projeto de portfólio com experiência completa de uma loja própria com fornecedores ou dropshipping. Não há intenção de vender neste momento. Pagamento, fornecedores e entregas serão demonstrados em ambiente de teste ou por simulação identificada.

Este repositório reúne a definição do produto, os requisitos e a estrutura proposta para construir a loja. Os documentos são uma base para discussão; itens marcados como proposta não representam decisões aprovadas.

7. [Entrega de portfólio](docs/07-portfolio.md): escopo completo, cenários demonstráveis e apresentação do projeto.

## Como usar

Primeiro, responder às perguntas de descoberta. Em seguida, revisar o MVP e selecionar a abordagem técnica. Só então detalhar o backlog de implementação e estimar esforço, prazo e custos.

Atualizar os documentos quando uma decisão mudar. Registrar o motivo e o impacto no registro de decisões, evitando que hipóteses antigas sejam tratadas como requisitos.

## Próximo marco

Definir o nicho fictício, a identidade visual e a stack conforme a experiência técnica e o objetivo profissional. O modelo de loja com fornecedores ou dropshipping já foi escolhido.
